## 阶段 2 的第一条训练链路

优先建立项目隔离环境，并验证 CPU PyTorch 与 NumPy；先迁移原版 PyMARL QMIX。

```text
Python API / CLI
  → 配置加载与算法组合验证
  → 小型确定性离散多智能体环境
  → EpisodeRunner / BasicMAC / RNNAgent
  → EpisodeBatch / ReplayBuffer
  → QLearner / QMixer
  → 一次真实梯度更新
  → checkpoint 保存、重新加载、评估
```

该链路已在确定性 toy 中通过，真实 SMAC 3m 因外部环境缺失未验证。第 2 阶段详见 STAGE2_REPORT.md。第 1 阶段的依赖缺失记录保留为历史证据。
