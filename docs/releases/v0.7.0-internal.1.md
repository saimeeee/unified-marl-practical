核心版本 0.7.0，内部分发修订 1。提供可发给同事安装的 CPU 包及中文说明；不需要网页、数据库或原始交付目录。

Python 解释器、系统运行库、真实数据、模型和外部仿真器未捆绑。先解压对应 ZIP，Windows 按包内 README 运行 install.ps1，Linux 运行 `bash install.sh`。安装使用独立 venv；自己的 Python 项目使用该解释器即可调用。

完整步骤见仓库 [中文使用说明书](https://github.com/saimeeee/unified-marl/blob/main/docs/USER_GUIDE.md)。源码自动 ZIP 不含离线依赖，请下载上表中完整文件名的安装包。

## 本次验证与范围

Windows 11 / CPython 3.12.14 / PyTorch 2.6.0+cpu：全新环境离线安装、重复安装、CLI、可选依赖导入、文件损坏检测，以及 QMIX toy 更新、保存加载、评估与恢复通过。安装器提前提示过深路径；不修改系统注册表。

Linux 按要求仅准备文件，未运行 Linux 安装或功能测试。Linux ZIP 内 34 个依赖 wheel 加核心 wheel，唯一需联网补充项为 hf-xet>=1.1.3,<2.0.0，未预锁具体版本和哈希。它不是完整离线包。

支持子集和未通过项保留，不新增真实环境、GPU、跨机或策略效果声明。详见 SUPPORT_MATRIX.md、KNOWN_ISSUES.md 和两个内部分发报告。
