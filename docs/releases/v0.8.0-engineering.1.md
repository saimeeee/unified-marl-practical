# unified-marl 0.8.0 工程应用包

面向仓储库存补货、交通信号协同和配电网建筑用能控制。下载对应系统的engineering ZIP，按包内docs/ENGINEERING_DISTRIBUTION.md安装；Python解释器、CityFlow、业务数据和行业预训练模型另行准备。

- warehouse：新增参数化库存环境、CSV业务输入、MFVFD/HMF等既有算法入口和补货数量输出；原ReplenishmentEnv后端保留。
- traffic：新增直接CityFlow.Engine适配及固定路口/phase映射、显式安全过渡和排队指标。
- powergrid：包内适配来源GridEnv，新增独立bounded Gaussian PPO连续动作训练、推理与完整训练状态。
- 三个模块统一train/evaluate/load_policy；unified-marl-app支持init/check/train/evaluate/act；参数模板、调用示例和中文指南一起提供。

本轮按用户要求不运行训练、仿真、真实环境或收敛实验，新能力为实现待用户测试。历史0.7.0验证不外推新实现。动态HMF/角色扩展和原缺失实验仍保留限制。

Windows / Linux x86_64均需CPython3.12。核心依赖可离线安装；Linux奖励模型功能需接收方联网补hf-xet；PowerGrid依赖按功能联网安装，CityFlow须自行安装本机可用引擎。两版均为CPU包；未做本轮安装运行或Linux实机测试。

所有附件提供SHA256SUMS及DELIVERY_MANIFEST；原始数据、模型、个人环境和缓存不随包上传。
