# 本地网页平台 v0.9.0-local.1

下载完整 ZIP，在自己的电脑打开实时仿真网页。四个已训练模型、库存/MPE/交通/电网场景数据和 CityFlow 编译源码都随包提供；运行不依赖训练服务器。

1. 安装并启动 Docker Desktop，使用 Linux 容器 / WSL2。
2. 下载附件 `unified-marl-local-v0.9.0-local.1.zip` 并完整解压，或使用仓库 Code → Download ZIP。
3. 双击根目录 `启动本地平台.cmd`。首次构建联网安装依赖，之后复用本机 CPU 镜像可离线运行。
4. 浏览器打开 `http://127.0.0.1:18765/`，选择场景、初始化，再开始或单步。用 `停止本地平台.cmd` 停止服务，运行记录保留。

暖白浅色界面，支持实时画布、暂停、单步、倍速、指标与动作、趋势、历史记录和 JSON 轨迹导出。新增兼容模型通过本地 `extra-models.json` 登记；算法与环境继续使用核心库的独立配置。

已从完整 Git archive 干净目录构建本机 Docker CPU 环境，并在 `--network none` 下完成四个真实回合：库存 24 周期、MPE 50 步、交通 32 决策 / 352 物理秒、电网 96 步。初始暂停、单步、暂停保持、并发导出和初始化停止均通过；671 份 bundle 文件及四份模型 SHA-256 已校验。附 `local-verification.json` 与 `SHA256SUMS.txt`。

这是单用户实时推理平台，网页目前不发起训练。Windows Docker Desktop 已实测；Linux/macOS 提供脚本但未在本轮实机验证。已有模型不代表已收敛，库存、MPE和电网的策略效果限制仍保留。首次构建需要下载基础镜像和依赖；ZIP 本身不是完整离线安装环境。
