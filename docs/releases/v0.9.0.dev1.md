# 0.9.0.dev1 · 算法与环境解耦的实用首版

这是实用首版预发布，目标为私有仓库 `saimeeee/unified-marl-practical` 的 `v0.9.0.dev1` 标签。本文描述交付内容与验收范围，不作为已经上传成功的证明；仓库、标签、附件与最终摘要以 [PUBLICATION_STATUS_090.md](https://github.com/saimeeee/unified-marl-practical/blob/main/docs/PUBLICATION_STATUS_090.md) 的实际发布回执为准。

## 本版新增

- 算法通过 `AlgorithmSpec/register_algorithm` 独立注册 Controller、Learner、默认参数、训练方式与能力要求；环境通过 `EnvironmentSpec/register_environment` 独立注册。
- YAML 单实验和算法 × 环境 × seed 矩阵：`run`、`run-suite`、`check`、`catalog`。
- 配置与能力预检、明确的错误状态、独立训练/评估 seeds、不会覆盖已有实验的输出目录、JSON/CSV 结果。
- 交付 MAPT 的 MPE `simple_spread` NumPy 粒子物理接入；现有参数化库存与原生 CityFlow 可使用统一在线入口。
- 插件模块列表随 checkpoint 保存；独立进程评估、推理、恢复与并行 worker 能重新导入插件。额外训练状态可使用显式保存/恢复钩子。
- `example/huber_iql` 教学插件：IQL 的 Smooth-L1 TD 损失变体，用来演示一个算法模块跨环境使用；不是三位作者原创算法，也不声称性能更优。

## 安装方式与附件边界

核心包名称：`unified_marl-0.9.0.dev1-py3-none-any.whl`。在具有私有仓库访问权限的账号下，按发布回执下载附件并核对 SHA-256，再在独立环境中安装：

```powershell
python -m pip install ./unified_marl-0.9.0.dev1-py3-none-any.whl
```

也可使用具有访问权限的 Git 认证，从目标仓库安装源码：

```powershell
git clone https://github.com/saimeeee/unified-marl-practical.git
cd unified-marl-practical
python -m pip install -e .
python -m unified_marl check examples/experiments/plugin_mpe.yaml --instantiate
python -m unified_marl run examples/experiments/plugin_mpe.yaml
python -m unified_marl run-suite examples/experiments/practical_suite.yaml
```

**本次 wheel 是核心安装包，不是离线依赖全家桶。** 它不包含 Python 解释器、全部平台依赖、CityFlow/StarCraft II 引擎、外部场景资产、真实业务数据或预训练模型。pip 根据元数据安装 NumPy、PyTorch、PyYAML 等依赖；离线安装需自行准备匹配平台的依赖包。仓库级 `examples/` 与文档应通过源码获取，不在核心 wheel 中。

包声明支持 **Python >= 3.10**，主要验收环境为 **Python 3.12、CPU**；其他 Python 版本与 GPU 未在本轮验收。无需先安装历史平台 ZIP 或历史补丁；本说明不表示已发布到 PyPI。

本次保留已验收 wheel 的原始字节；wheel 内嵌 README 是本地验收时的快照，最新使用说明以仓库和本 Release 指南为准，387 份运行源码/资源仍与当前 `src` 一致。

## 范围限制

- 通用在线插件协议支持离散动作、固定智能体数、团队标量奖励、全局状态与动作掩码。
- 自带 MPE 仅支持 `simple_spread`。原 SMAC/StarCraft II、原 ReplenishmentEnv 需要外部依赖及场景资产，本轮未实跑。
- `inventory` 是包内参数化库存仿真，与外部 ReplenishmentEnv 不同；交通需要自行准备 CityFlow 引擎及相匹配的路网/车流。
- 连续动作电网仍保留原应用入口，不进入当前离散插件矩阵，也不会被隐式离散化。
- 角色/均场、离线/偏好、奖励模型、ZMQ/K8s 等历史路径不因本次预发布而获得“全部跨环境可用”的承诺。
- 恢复训练保存学习器、优化器、回放及全局 RNG，不保存外部仿真器的全部内部物理状态。
- 独立评估 seed 不等于独立业务数据；短训练检查不证明长期收敛、论文复现、GPU/跨机部署或真实业务收益。
