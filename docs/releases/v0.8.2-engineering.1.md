# unified-marl 0.8.2 工程修复版

本版整理三轮测试后的最小可用链路，面向仓储补货、交通信号和配电网建筑用能控制。

- 修复仓储API/CLI恢复时自动seed误判，评估增加实际步数。
- 修复电网净用电量观测中的光伏列表乘法；预热与策略控制分开计数，4步回合对应4次控制。
- 修复功能加装降级，原路径安装器保留核心版本，备份和清单追踪保留。
- 用户第三轮报告：仓储更新/恢复/推理、CityFlow官方单路口PPO、电网公开CityLearn替代数据上的更新/保存/完整恢复通过。不是本机重跑或真实业务收益验收。

## 下载与安装

已有0.8.0/0.8.1工程基础环境：下载本版hotfix ZIP及.sha256，使用目标`.venv`执行其中的`install_patch.py --bundle 原工程包目录`。仅安装wheel不能修复旧安装入口。首次安装先下载0.8.0工程Release中对应Windows/Linux基础ZIP，依赖wheelhouse可以复用。

补丁及wheel保留第三轮实际测试的原始字节和SHA256。源码包更新了验收说明、定向诊断及发布工具；运行源码/资源与该wheel一致。
