# 本机实时仿真平台验收记录

日期：2026-10-29。**本地构建与四场景无外网运行验收通过；GitHub 发布仍进行中。**

交付目标为从 GitHub 下载完整仓库后，在用户电脑上运行网页、模型推理与环境仿真。源码与 `demos/live-platform/bundle/` 一并交付，包含库存、MPE、CityFlow 交通、电网四场景的原训练模型、配置、数据和 CityFlow 源码。平台使用 Docker Desktop 的 Linux CPU 容器，本机浏览器访问 `http://127.0.0.1:18765/`，无需 SSH 或远程训练机器。

## 本次验证方式

从待发布 Git 索引生成源码归档，解压到干净的中文目录后构建 Docker 镜像，未引用开发目录之外的训练模型或场景文件。构建使用公开的 `python:3.12-slim-bookworm` 基础镜像、PyTorch 2.6 CPU 和随包 CityFlow 源码，依赖检查 `pip check` 通过。

构建完成后，使用 `docker run --network none` 启动独立容器，在容器内通过 HTTP 调用实际已保存模型与原生仿真器。该容器没有外部网络，四个完整回合均成功。671 个 bundle 文件完成校验，四份权重的 SHA-256 与原训练产物一致，没有重新训练或替换模型。

## 使用与验收边界

首次构建需要联网下载基础镜像和依赖；镜像构建成功后，复用本机镜像的离线推理已实际验证。代码更新后通过 `-Rebuild` 重新构建，缺少构建依赖时仍需联网。运行记录与额外模型保存在本机 `local-state/`，停止脚本只停止容器，不删除这些数据。具体步骤见 [本地平台说明](../demos/live-platform/README.zh-CN.md)。

平台保留浅色界面，是单用户、单运行会话的模型推理与仿真工具；网页不发起训练，没有多用户任务调度。本次验证证明完整本地运行链路，不证明策略收敛或业务效果。库存弱于规则基线、MPE 严格覆盖率低、电网仍有越限且综合奖励未改善等既有效果边界保持。

本机验证独立于早期服务器验证。当前尚不宣称本轮 GitHub 已发布；远端发布回执及下载内容核对需另行记录。
