Adaptations:
- package-relative imports; an environment-local NumPy RandomState replaces
  global random calls, preserving the legacy random-number generator family;
- at exactly coincident colliding particle positions, the source divides by
  zero; a fixed +x separating direction makes that undefined contact finite.
  The original expression is unchanged for nonzero distances;
- a new MultiAgentEnv adapter validates discrete actions, exposes scalar team
  reward, and represents the finite horizon as a time-limit truncation;
- the new adapter's central state is the flattened local-observation array,
  matching the source wrapper's concatenated shared-observation construction.

Unchanged semantics: dt=0.1, damping=0.25, soft contact forces, agent radius
0.15, force sensitivity=5, reset positions, scenario observations, silent
communication fields, agent IDs and cooperative reward summation. In
particular, the delivered reward includes a -1 self-collision baseline per
agent and counts each physical pair collision for both participating agents.
Action indices match the source default one-hot path: 0 stay, 1 +x, 2 -x,
3 +y, 4 -y. The world has no arena walls or clipping to the initial range.

Only the cooperative simple_spread task is exposed. Other MPE scenarios are
not claimed as supported. NumPy is the only third-party runtime dependency
of this environment implementation. The original delivery was not modified.
